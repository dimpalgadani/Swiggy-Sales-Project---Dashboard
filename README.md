# Swiggy Sales Project - Dashboard


## 📊 Swiggy Sales Analysis Dashboard | Tableau

### 🔍 Project Overview

This Tableau project analyzes Swiggy sales data to provide clear insights into order trends, revenue performance, and customer behavior.
The dashboard is designed to help stakeholders understand sales performance, identify high-performing categories, and make data-driven business decisions.

### 🎯 Objectives

Analyze overall sales and revenue trends

Identify top-performing restaurants and food categories

Track order volume and sales growth over time

Support business and operational decision-making

### 📌 Key Dashboard Features

Interactive Tableau dashboard

Total orders, total sales, and average order value KPIs

Category-wise and restaurant-wise sales analysis

Trend analysis using time-based charts

User-friendly filters for deeper exploration

### 📈 Insights Generated

Identification of high and low revenue-generating categories

Peak order periods and sales trends

Performance comparison across restaurants

Customer ordering behavior patterns

### 🛠 Tools & Technologies

Tableau Desktop

CSV dataset

Data cleaning and preparation

Data visualization & storytelling
